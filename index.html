01 / OVERVIEW

APA ITU
WEB BIOGRAFIS?

Bukan sekadar halaman web, melainkan representasi identitas dalam bentuk digital.

Web Biografis merupakan website yang dirancang untuk memperkenalkan identitas, latar belakang pendidikan, pengalaman, minat, keahlian, serta perjalanan akademik seseorang melalui media digital.

Website ini dikembangkan sebagai bagian dari pembelajaran mata kuliah Pemrograman, dengan menerapkan konsep dasar pengembangan web, penyusunan struktur dokumen, pengaturan tampilan, serta interaksi antara pengguna dan halaman web.

Selain menjadi media pengenalan diri, proyek ini juga menjadi sarana untuk memahami bagaimana teknologi web dapat digunakan dalam membangun identitas digital yang informatif, terstruktur, dan mudah diakses.

02 / LEARNING OBJECTIVES

BELAJAR DARI
DASAR.

Mata kuliah Pemrograman menjadi landasan untuk memahami logika, struktur, dan proses pembangunan sebuah aplikasi. Dalam proyek ini, konsep tersebut diterapkan melalui pembuatan website menggunakan teknologi pengembangan web dasar.

Proses pembelajaran tidak hanya berfokus pada penulisan kode, tetapi juga pada bagaimana menyusun informasi, merancang antarmuka, dan memberikan pengalaman yang baik kepada pengguna.

STRUKTUR

02

03

Tujuan proyek: menerapkan dasar pengembangan web melalui produk nyata sekaligus mengembangkan pemahaman tentang desain antarmuka dan pengalaman pengguna.

03 / TECHNOLOGY STACK

THREE TOOLS.
ONE WEBSITE.

Website ini menggunakan tiga teknologi utama yang memiliki fungsi berbeda, tetapi bekerja bersama dalam proses pengembangan halaman web.

01 STRUCTURE

HTML5

HyperText Markup Language digunakan untuk membangun struktur dan menyusun konten website, mulai dari judul, paragraf, navigasi, hingga bagian biografi.

PERAN: STRUKTUR KONTEN

02 PRESENTATION

CSS

Cascading Style Sheets digunakan untuk mengatur tampilan visual, palet warna, tipografi, tata letak, responsivitas, dan karakter desain Brutalism.

PERAN: TAMPILAN VISUAL

03 INTERACTION

JavaScript

JavaScript digunakan untuk mengembangkan fitur interaktif, seperti pengaturan tema, perubahan ukuran teks, dan penyimpanan preferensi tampilan pengguna.

PERAN: INTERAKTIVITAS

Ketiga teknologi tersebut memiliki fungsi yang saling melengkapi. HTML membentuk struktur, CSS mengatur presentasi, sedangkan JavaScript memungkinkan perilaku interaktif.

04 / VISUAL IDENTITY

BRUTALISM.
BOLD BY DESIGN.

Berani. Kontras. Tidak Biasa.

Brutalism merupakan pendekatan desain yang menonjolkan keterusterangan visual, struktur yang tegas, tipografi kuat, garis yang terlihat, dan penggunaan warna kontras.

Dalam website ini, karakter tersebut diterapkan melalui komposisi yang lugas, judul berukuran besar, blok warna yang dominan, garis tebal, serta elemen antarmuka yang tidak berusaha menyembunyikan struktur desainnya.

Pendekatan ini dipilih agar website memiliki karakter visual yang kuat sekaligus membedakan proyek dari desain portofolio konvensional yang cenderung minimalis dan netral.
